# TeleSham — Frontend

واجهة عربية RTL متجاوبة مستوحاة من الصورة المرفقة، مبنية بـ HTML وCSS وJavaScript فقط، بدون إطار عمل أو خطوات بناء.

## التشغيل
1. فك ضغط المجلد إن كان مضغوطاً.
2. افتح `index.html` في المتصفح، أو استخدم إضافة Live Server في VS Code.

## الملفات
- `index.html` — بنية الصفحة والأقسام.
- `style.css` — التصميم والاستجابة للموبايل والكمبيوتر.
- `script.js` — قائمة الهاتف، أزرار تفاصيل العروض، ورسالة الاشتراك التجريبية.

## ملاحظات
- صور الصفحة والخط والخريطة يتم تحميلها من الإنترنت.
- النموذج والأزرار تجريبية من ناحية البيانات؛ ربطها بواجهة API أو نظام دفع أو خدمة بريد يحتاج backend.
- عدّل بيانات الأسعار والشركاء ووسائل التواصل قبل النشر.
